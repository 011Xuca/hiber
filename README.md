# Hiber

Sleeps the tabs you don't use, blocks ads (YouTube included) and cuts RAM, CPU and network use.
Chrome, Edge, Brave, Opera, Vivaldi and Firefox. Version 1.0.2 (see [`CHANGELOG.md`](CHANGELOG.md)).

## What it does

**Saves resources**
- Sleeps inactive tabs (it never touches tabs that play sound or video, or have a half-filled form).
- Trims animations, heavy effects, images and preloading; pauses muted videos in hidden tabs.
- Options to block fonts and images, plus a phone-like mode.
- Several ready-made levels (from gentle to aggressive) and a popup to tune each setting.

**Blocks ads**
- **Network:** blocks tracker, ad and pop-under domains, and typical ad paths.
- **Public list:** downloads Peter Lowe's list (about 3,500 ad domains) and refreshes itself every ~3 days.
  It only downloads domain names, never code. A built-in list of domains that are never blocked (YouTube, Google,
  CDNs, payments, players) can be turned off from the popup.
- **Pop-ups and redirects** (anime, series and movie sites): stops windows that open when you click the video, go
  fullscreen or click anywhere; disables invisible click-catching layers; closes the ad tab if one still opens;
  drops fake-banner iframes ("verify you're human", "Sign in").
- **YouTube:** skips the ad using the player's own function; if that fails, it plays it muted at 2x with "Skip" visible.
- **Twitch:** during a break it uses the ad-free stream (360p) and returns to full quality afterwards; if that fails, it mutes the ad.
- **Kick:** cuts video ads and banners without touching the live stream, which keeps its normal quality.

**Extras:** RAM and CPU limiter (off by default), floating video (Alt+P), automatic YouTube quality, and a red "!"
badge on the icon when a new version is out on GitHub.

**What it doesn't do:** it doesn't touch logins, payments, downloads or a site's normal redirects.

## Install

**Chrome, Edge, Brave, Opera / Opera GX, Vivaldi** (all Chromium): open the extensions page
(`chrome://extensions`, `edge://extensions`, `brave://extensions`, `opera://extensions`), turn on **Developer mode**
and click **Load unpacked**. Pick this folder.
You can also use the zips in `dist/` (see below).

**Firefox** (128 or newer): run `node build-firefox.js`, open `about:debugging#/runtime/this-firefox`,
**Load Temporary Add-on…** and pick `firefox/manifest.json`. It's temporary: it disappears when Firefox closes.
To keep it permanently it has to be signed on addons.mozilla.org.

Safari is not supported.

To update a hand-loaded version: click **Reload extension** (bottom of the popup) or the reload arrow on the
extensions page.

## Build the zips

```
python build-zips.py
```

It runs `build-firefox.js` and writes `dist/hiber-chrome-<version>.zip`, `-edge`, `-opera` and `-firefox`.
The version comes from `version.txt`: push it to GitHub (`main` branch) too so the update notice matches.

The zips are uploaded to the GitHub **release** (`hiber-<browser>-<version>.zip`, with that exact name). Hiber's page
on `011xuca.github.io` and Brío's Download button look up the latest release and download the zip that fits the
user's browser (Chrome/Brave/Vivaldi → chrome, Edge, Opera, Firefox).

## What changes per browser

- Firefox doesn't expose free memory (the popup only shows sleeping tabs) and can't open its settings from the extension.
  The RAM and CPU limiter doesn't work on Firefox: it has no `system.cpu` or `performance.memory` (the switches do nothing).
- Chrome and Edge use a service worker; Firefox uses background scripts. `firefox/` is generated by `node build-firefox.js`:
  don't edit it by hand.
- The popup detects the browser and shows its own tips (Brave Shields, GX Control, Edge sleeping tabs, etc.).

## Privacy

Hiber sends no data to any server. The only things it does on the network are downloading the public domain list
(`pgl.yoyo.org`) every few days and reading this repo's `version.txt` on GitHub (`raw.githubusercontent.com`) every
12 hours for the update notice. Settings are stored in the browser.

## Limits

- **Ads change domain all the time.** Rotating pop-up domains can slip through until they show up in a list. If one
  gets through, open DevTools → Network, copy the URL and add it to `TRACKERS` (`background.js`) and to `AD`
  (`main.js`); both lists must stay identical.
- **Video ads inside the player** (for example an ad before an episode) are only blocked if we know the domain
  they are served from.
- **YouTube** changes its code often, so it can stop working: `yt.js` then needs adjusting.
- A legitimate site could break with the public list. If that happens, turn it off from the popup and tell us which one it was.

## Files

| File | Purpose |
|---|---|
| `manifest.json` | Extension configuration (Chrome/Edge/Opera). |
| `background.js` | Network rules, public list, tab sleeping, closing ad tabs. |
| `content.js` | Visual and loading tweaks on each page; hides ad banners. |
| `main.js` | Runs in the page and iframes: stops ad pop-ups and redirects. |
| `yt.js` | YouTube ad blocking. |
| `popup.html` / `popup.js` | The extension window. |
| `defaults.js` | Default settings and levels. |

## 🇪🇸 Español

Duerme las pestañas que no usás, bloquea anuncios (incluido YouTube) y recorta RAM, CPU y red.
Chrome, Edge, Brave, Opera, Vivaldi y Firefox. Versión 1.0.2 (ver [`CHANGELOG.md`](CHANGELOG.md)).

### Qué hace

**Ahorra recursos**
- Duerme las pestañas inactivas (no toca las que suenan, reproducen video o tienen un formulario a medio escribir).
- Recorta animaciones, efectos pesados, imágenes y precarga; pausa videos sin sonido en pestañas ocultas.
- Opciones para bloquear fuentes e imágenes y modo celu.
- Varios niveles listos (de más tranqui a más a fondo) y un popup para ajustar cada cosa.

**Bloquea anuncios**
- **Red:** bloquea dominios de rastreadores, anuncios y pop-unders, y rutas típicas de publicidad.
- **Lista pública:** baja la lista de Peter Lowe (unos 3 500 dominios de anuncios) y se actualiza sola cada ~3 días.
  Solo baja nombres de dominio, nunca código. Hay una lista interna de dominios que nunca se bloquean (YouTube, Google,
  CDNs, pagos, reproductores) y se puede apagar desde el popup.
- **Pop-ups y redirecciones** (webs de anime, series y películas): frena las ventanas que se abren al hacer clic en el
  video, en pantalla completa o en cualquier parte; desactiva las capas invisibles que capturan el clic; cierra la
  pestaña de anuncio que igual se abra; descarta los iframes de carteles falsos ("verificá que sos humano", "Sign in").
- **YouTube:** corta el anuncio con la función del propio reproductor; si no toma, lo pasa silenciado y a x2 con "Saltar" visible.
- **Twitch:** durante un corte usa el stream sin anuncios (360p) y vuelve a la calidad completa al terminar; si falla, silencia el anuncio.
- **Kick:** corta los videos de publicidad y los banners sin tocar el directo, que sigue en su calidad normal.

**Extras:** limitador de RAM y CPU (apagado por defecto), video flotante (Alt+P), calidad automática de YouTube y aviso
rojo "!" en el icono cuando hay una versión nueva en GitHub.

**Lo que no hace:** no toca los logins, pagos, descargas ni las redirecciones normales de una web.

### Instalar

**Chrome, Edge, Brave, Opera / Opera GX, Vivaldi** (todos Chromium): abrí la página de extensiones
(`chrome://extensions`, `edge://extensions`, `brave://extensions`, `opera://extensions`), activá **Developer mode**
y tocá **Load unpacked** (en Opera: **Cargar descomprimida**). Elegí esta carpeta.
También podés usar los zips de `dist/` (ver abajo).

**Firefox** (128 o más): corré `node build-firefox.js`, abrí `about:debugging#/runtime/this-firefox`,
**Load Temporary Add-on…** y elegí `firefox/manifest.json`. Es temporal: se borra al cerrar Firefox.
Para dejarla fija hay que firmarla en addons.mozilla.org.

Safari no está soportado.

Para actualizar una versión cargada a mano: tocá **Recargar extensión** (abajo del popup) o la flecha de recarga en la
página de extensiones.

### Generar los zips

```
python build-zips.py
```

Corre `build-firefox.js` y deja `dist/hiber-chrome-<versión>.zip`, `-edge`, `-opera` y `-firefox`.
La versión sale de `version.txt`: subila también a GitHub (rama `main`) para que el aviso de actualización coincida.

Los zips se suben al **release** de GitHub (`hiber-<navegador>-<versión>.zip`, con ese nombre exacto). La página
de Hiber en `011xuca.github.io` y el botón Descargar de Brío buscan el último release y bajan solos el zip
que corresponde al navegador del usuario (Chrome/Brave/Vivaldi → chrome, Edge, Opera, Firefox).

### Qué cambia según el navegador

- Firefox no expone la memoria libre (el popup solo muestra pestañas dormidas) ni puede abrir sus ajustes desde la extensión.
  El limitador de RAM y CPU no funciona en Firefox: no tiene `system.cpu` ni `performance.memory` (los interruptores no hacen nada).
- Chrome y Edge usan un service worker; Firefox usa scripts de fondo. `firefox/` se genera con `node build-firefox.js`:
  no lo edites a mano.
- El popup detecta el navegador y muestra tips propios (Brave Shields, GX Control, pestañas en suspensión de Edge, etc.).

### Privacidad

Hiber no manda datos a ningún servidor. Lo único que hace en la red es bajar la lista pública de dominios
(`pgl.yoyo.org`) cada pocos días y leer `version.txt` de este repo en GitHub (`raw.githubusercontent.com`) cada
12 horas para el aviso de actualización. Los ajustes se guardan en el navegador.

### Límites

- **Los anuncios cambian de dominio todo el tiempo.** Los dominios de pop-ups que rotan pueden colarse hasta que
  aparecen en una lista. Si te sale uno, abrí DevTools → Network, copiá la URL y agregala a `TRACKERS`
  (`background.js`) y a `AD` (`main.js`); las dos listas tienen que quedar iguales.
- **Anuncios de video dentro del reproductor** (por ejemplo una publicidad antes del capítulo) solo se bloquean si
  conocemos el dominio desde el que se sirven.
- **YouTube** cambia su código seguido, así que puede dejar de andar: ahí hay que ajustar `yt.js`.
- Una web legítima podría romperse con la lista pública. Si pasa, apagala desde el popup y avisá cuál fue.
